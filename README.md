# سراج - Siraj (Warteel)

تطبيق ويب وسطح مكتب إسلامي شامل (مواقيت الصلاة، الأذكار، القرآن، والمزيد).
مبني باستخدام **Vite** و **Tauri**.

## المميزات
- عرض مواقيت الصلاة بدقة.
- أذكار الصباح والمساء.
- قراءة القرآن الكريم.
- تطبيق سطح مكتب سريع وخفيف مبني باستخدام Tauri.
- تطبيق ويب سريع مبني باستخدام Vite.

## المتطلبات الأساسية
- [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث، يفضل 20 كما هو موضح في `.nvmrc`).
- [Rust](https://www.rust-lang.org/) (إذا كنت ترغب في بناء تطبيق سطح المكتب عبر Tauri).

## التثبيت والتشغيل المحلي

1. **تثبيت الحزم:**
   ```bash
   npm install
   ```

2. **تشغيل نسخة الويب للتطوير:**
   ```bash
   npm run dev
   ```

3. **تشغيل نسخة سطح المكتب (Tauri) للتطوير:**
   ```bash
   npm run tauri dev
   ```

## بناء المشروع (Production)

- **لبناء تطبيق الويب:**
  ```bash
  npm run build
  ```
  سيتم إنشاء الملفات في مجلد `dist/`.

- **لبناء تطبيق سطح المكتب:**
  ```bash
  npm run tauri build
  ```

## الاستضافة على Cloudflare Pages

المشروع جاهز للاستضافة المباشرة على **Cloudflare Pages**.
- **إعدادات البناء:**
  - **Framework preset:** `Vite`
  - **Build command:** `npm run build`
  - **Build output directory:** `dist`
- المشروع يحتوي على ملف `public/_redirects` لضمان عمل التوجيه (Routing) بسلاسة.
